# Data inventory

Every data file in this repository, where it came from, its licence and its checksum. Check D1 of the validation suite (`checks/run_all_checks.py`) recomputes the checksums of the files under `data/raw/`: SHA-256 of the file's bytes for text files (git stores them unconverted, `.gitattributes`, so every platform gets the bytes as published; the IFPRI SAMs are identical to IFPRI's originals), SHA-256 of the cell values for Excel files. A mismatch means a file has changed; results must not be used until it is explained.

Files that are **not** here, and why, are listed in `docs/STATUS.md`; the folders' README files explain how to obtain them.
